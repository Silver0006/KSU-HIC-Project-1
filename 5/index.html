The Eight Golden Rules of Interface Design

As defined by Ben Shneiderman

  • 1. Strive for consistency
  • 2. Seek universal usability
  • 3. Offer informative feedback
  • 4. Design dialogs to yield closure
  • 5. Prevent errors
  • 6. Permit easy reversal of actions
  • 7. Keep users in control
  • 8. Reduce short-term memory load

5. Prevent errors

Errors should be avoided whenever possible. It makes sense; ideally you don't want errors to happen, but sometimes it's unavoidable. This is why it is important to make sure serious errors don't affect the user negatively. If an error occurs, the error should be handled cleanly. If the error is cause by the user, it should provide feedback to help them correct the mistake. A mistake should be easily fixable. Shneiderman's website provides the example of a user entering their email.1 If they type something wrong you shouldn't make them start over. Point out the error and allow them to correct it. Prompting before making important decisions is also wise. You want to make sure that the user fully understands what they are doing. We're not just correcting for computer errors, but human error. The clearer you make an option, the safer you are.
