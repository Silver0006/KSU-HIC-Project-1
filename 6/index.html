The Eight Golden Rules of Interface Design

As defined by Ben Shneiderman

  • 1. Strive for consistency
  • 2. Seek universal usability
  • 3. Offer informative feedback
  • 4. Design dialogs to yield closure
  • 5. Prevent errors
  • 6. Permit easy reversal of actions
  • 7. Keep users in control
  • 8. Reduce short-term memory load

4. Permit easy reversal of actions

Users are fallible so ensuring that there is an easy way to retrive their data they accidently deleted is important to a good interface.

This page is pretty simple. Type anything in the box and if you so happen to click the Clear button you can undo your mistake.

Try it

By ensuring you have a fail safe in an undo button it unsures that even when the user messes up, the interface will save a backup for the user. Which is the 6th golden rule.
