The Eight Golden Rules of Interface Design

As defined by Ben Shneiderman

  • 1. Strive for consistency
  • 2. Seek universal usability
  • 3. Offer informative feedback
  • 4. Design dialogs to yield closure
  • 5. Prevent errors
  • 6. Permit easy reversal of actions
  • 7. Keep users in control
  • 8. Reduce short-term memory load

1. Strive for consistency

A UX designer should strive to provide a consistent interface and experience. Humans are fairly good at recognizing patterns. By repeating fonts, colors, and other element, you can help to build up muscle memory that will make your design easier to navigate. This web presentation makes sure to keep a consistent menu, which you can see above. You might not have even thought about it. If we had set the menu in a different position each time, you probably would have. Okay so consistency is good, but are there any exceptions? Yep. As I already noted, your attention is drawn to inconsistency. You can build a pattern and then break it to create contrast; still, this method should be used sparingly.
