The Eight Golden Rules of Interface Design

As defined by Ben Shneiderman

  • 1. Strive for consistency
  • 2. Seek universal usability
  • 3. Offer informative feedback
  • 4. Design dialogs to yield closure
  • 5. Prevent errors
  • 6. Permit easy reversal of actions
  • 7. Keep users in control
  • 8. Reduce short-term memory load

4. Design dialogs to yield closure

The ending to a good interface is confirmation that an action went through. If there is no confirmation at the end of an action, the user may get confused and revert the action or spam it multiple times. A clear confirmation allows the user to understand that they are done on their end for that action.
